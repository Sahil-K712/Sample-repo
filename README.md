

# Construct Week Project - CASIO Website Clone

**HTML**, **CSS**, **JavaScript**, **Node.js**, **Firebase**, **Other Libraries & Tools**

This project is part of **Construct Week**, where we are creating a **CASIO WEBSITE CLONE** using **HTML**, **CSS**, **JavaScript**, and backend tools like **Node.js** and **Firebase**. The project spans over four days, with specific tasks assigned to each team member. Below is a detailed breakdown of the tasks and responsibilities.

## Project Overview

We are building a multi-page website that includes the following key pages:
- **Home page**
- **Support and Corporate pages**
- **Login Page**
- **Checkout Page**
- **Other relevant pages**

The project will include a **responsive design**, **interactive features** using **JavaScript**, and a clean, modern layout, with a particular focus on integrating Firebase for authentication and dynamic content.
